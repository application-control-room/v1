Error codes

Every error response has a stable code (see Responses and errors). Statuses are the usual ones for the code; a few codes are reused with different statuses and are noted.

Generic​

CodeStatusMeaning
VALIDATION_ERROR400Body, query or params failed validation (see errors[]). Unknown fields are rejected
NOTHING_TO_UPDATE400An empty PATCH body
BAD_REQUEST, UNAUTHORIZED, FORBIDDEN, NOT_FOUND, CONFLICT, PAYLOAD_TOO_LARGE, UNPROCESSABLE_ENTITY, TOO_MANY_REQUESTS, INTERNAL_SERVER_ERROR, SERVICE_UNAVAILABLEby statusFallbacks when no domain code applies
RATE_LIMITED429Global throttle. Honour Retry-After

Sign-in, sessions and devices​

CodeStatusMeaning / action
AUTH_REQUIRED401No Bearer token on a protected route
ACCESS_TOKEN_EXPIRED, ACCESS_TOKEN_INVALID401Refresh, then retry. The ACR console does this automatically
SESSION_INVALID, SESSION_REVOKED, SESSION_EXPIRED401Sign in again
REFRESH_MISSING, REFRESH_INVALID, REFRESH_EXPIRED401No usable refresh cookie. Sign in
REFRESH_CONCURRENT401Another request rotated the token a moment ago. Retry with the newer cookie (session is kept)
REFRESH_REUSE401An old refresh token was replayed. The session was revoked
DEVICE_TOKEN_MISSING, DEVICE_TOKEN_INVALID, DEVICE_TOKEN_EXPIRED, DEVICE_TOKEN_REVOKED401Register the device again (the ACR console does this automatically)
DEVICE_REGISTER_RATE_LIMITED429Too many registrations from this IP
INVALID_CREDENTIALS401Wrong e-mail or password
ACCOUNT_LOCKED423Too many failures. Wait for the lockout (LOGIN_LOCKOUT_MINUTES)
EMAIL_NOT_VERIFIED403Verify the e-mail first
ACCOUNT_INACTIVE403 (401 when resolving a session)The account is disabled
EMAIL_TAKEN, PHONE_TAKEN409Already used by another account
PHONE_INVALID400Not a 10-digit Indian mobile number starting 6–9
CURRENT_PASSWORD_REQUIRED, CURRENT_PASSWORD_INVALID400Change-password problems (deliberately not 401)
RESET_LINK_INVALID, RESET_LINK_EXPIRED400The reset link is unusable. Start again
GOOGLE_TOKEN_INVALID401Google credential rejected
GOOGLE_ACCOUNT_MISMATCH409The Google account conflicts with the existing link
GOOGLE_SIGNIN_DISABLED503GOOGLE_CLIENT_ID is not configured

Captcha and OTP​

CodeStatusMeaning
CAPTCHA_REQUIRED, CAPTCHA_INVALID400Missing or wrong answer (details.attemptsLeft)
CAPTCHA_EXPIRED, CAPTCHA_ATTEMPTS_EXCEEDED400Request a new challenge
CAPTCHA_NOT_FOUND404The challenge image was consumed, expired or never existed
CAPTCHA_RATE_LIMITED429Too many generate/verify calls
OTP_INVALID, OTP_EXPIRED, OTP_NOT_FOUND, OTP_ATTEMPTS_EXCEEDED400Wrong, expired or burned code. Request a new one
OTP_RESEND_RATE_LIMITED429Resend limit reached

Apps, members and invitations​

CodeStatusMeaning
APP_NOT_FOUND404Not a member, or the app is deleted (existence is never leaked)
APP_FORBIDDEN403Role too low (details.role, details.required)
APP_ARCHIVED409A write on an archived app. 403 when an SDK request comes from an archived app
APP_LIMIT_REACHED403You (or the new owner, on a transfer) are billing owner of as many apps as the plan allows
MEMBER_LIMIT_REACHED403The app's plan member limit is reached (pending invitations count when inviting)
API_KEY_LIMIT_REACHED403The app's plan API key limit is reached (keys not revoked)
APP_UNAVAILABLE409The app cannot accept the operation (for example an invitation for a deleted app)
MEMBER_NOT_FOUND404Unknown member
LAST_OWNER409Would leave the app without an owner
MEMBER_ALREADY_OWNER409Transfer target is already an owner
TRANSFER_TARGET_INVALID400Transfer target is yourself
APP_MEMBER_EXISTS409The invitee is already a member
INVITATION_PENDING409A pending invitation for that e-mail already exists
INVITATION_NOT_FOUND404Unknown token or id
INVITATION_NOT_PENDING, INVITATION_ACCEPTED409Already handled
INVITATION_EXPIRED, INVITATION_REVOKED410Gone
INVITATION_EMAIL_MISMATCH403The signed-in account's e-mail differs from the invitation
INVITATION_RESEND_COOLDOWN429Wait details.retryAfterSeconds
INVITATION_DELIVERY_FAILED503The invitation e-mail could not be sent; the invitation stays pending, resend it

CodeStatusMeaning
CREDENTIAL_INVALID401Missing, malformed or unknown key, or wrong secret
CREDENTIAL_REVOKED401Key revoked or its app deleted. 409 when rotating an already revoked key
CREDENTIAL_EXPIRED401Past its expiry
ORIGIN_NOT_ALLOWED403Client key used from an origin not on its list
KEY_TYPE_NOT_ALLOWED403A client key used a server-only route (the public events API)
API_CREDENTIAL_NOT_FOUND404Unknown key id in the ACR console API
INGEST_RATE_LIMITED429Per-key request budget exhausted
INGEST_BACKPRESSURE429API buffer full; retry shortly (Retry-After: 5)
SDK_CONFIG_RATE_LIMITED429Control polling budget exhausted
SCHEMA_VERSION_UNSUPPORTED422schemaVersion not supported (details.supported)
INGEST_REJECTED422No item in the batch was valid (details.errors)
EVENT_QUOTA_EXCEEDED403The billing owner's monthly event quota is used up (details.used, details.resetsAt). SDKs drop the batch
EVENT_PAYLOAD_INVALID400Public events payload not acceptable (for example too deep)

Per-item rejection codes inside a 202: VALIDATION_FAILED, OCCURRED_AT_INVALID, OCCURRED_AT_OUT_OF_RANGE.

CodeStatusMeaning
DATE_RANGE_INVALID400from is not before to
DATE_RANGE_TOO_LARGE400More than 90 days
DATE_RANGE_BEYOND_RETENTION400The whole range is older than the app's plan keeps (details.retentionDays, details.earliest). A range that only starts too early is clamped instead
CURSOR_INVALID, CURSOR_CONFLICT400Malformed cursor; cursor and after together
TELEMETRY_EVENT_NOT_FOUND404Unknown event id
VISITOR_NOT_FOUND404Unknown anonymous id
ERROR_ISSUE_NOT_FOUND404The fingerprint has no occurrence in the range

Controls​

CodeStatusMeaning
RELEASE_VERSIONS_INVALID400Minimum version is greater than the latest
FLAG_KEY_EXISTS409Flag key already used in this app
FLAG_LIMIT_REACHED409The app's plan flag limit is reached (Free: 200)
FLAG_VALUE_INVALID400value or defaultValue does not match type (details.problems)
FLAG_NOT_FOUND404Unknown flag id
ANNOUNCEMENT_SCHEDULE_INVALID400endsAt not after startsAt, or not in the future
ANNOUNCEMENT_ARCHIVED409Cannot edit an archived announcement
ANNOUNCEMENT_NOT_FOUND404Unknown id
COMMAND_PARAMS_INVALID400Invalid command params (details.messages)
COMMAND_NOT_FOUND404Unknown id

Plan limits​

Every limit error carries details: { limit, max, planId, planName }, where limit is the limit key and max the plan's value, and a message such as "This app's plan (Free) allows 20 monitors per app." Other limit codes: UPTIME_LIMIT_REACHED (403), ALERT_RULE_LIMIT_REACHED (403), ALERT_CHANNEL_LIMIT_REACHED (403) and PM2_HOST_LIMIT_REACHED (403), plus the ones listed above.

Server-side maintenance (from the SDKs, not the API)​

503 with { "error": "MAINTENANCE", "message", "endsAt" } and Retry-After, answered by the Express maintenance middleware or the NestJS ACRMaintenanceGuard while maintenance is on. This is an application response, not an ACR API error.
