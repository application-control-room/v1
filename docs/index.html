ACR documentation

ACR (Application Control Room) lets a team watch and steer the applications it runs. Install one SDK in an app, and ACR shows its visitors, events, errors, logs, performance and runtime health. From the same ACR console you can switch features on and off, put the app into maintenance, announce changes, ask browsers to clear their caches, and stop data collection at once.

New here?

Read What is ACR, then follow Connect your first app to see data arrive in the ACR console.

Pick your path​

Use the ACR console

Create apps, invite teammates, create API keys and read the analytics, error and log pages. Start with Apps and API keys.

Instrument an application

Install the browser, React, Angular, Node.js, Express or NestJS SDK and use feature flags and remote control. Start with Choosing an SDK.

Send custom events

Track business actions such as sign-ups and orders, from an SDK or from any language over HTTP. Start with Events and the public events API.

Fix a problem

No data arriving, a rejected key, a rate limit or a control change that does not apply. Start with Troubleshooting.
