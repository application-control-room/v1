Apps

An app is one deployment target. Create one app per deployment: "Shop – production" and "Shop – staging" are two apps with separate keys, members, telemetry and controls.

Create an app​

Open Create app from the app switcher (top left), or you are taken there automatically when you have none.

FieldNotes
Name2–120 characters
Stageproduction, staging, development or other. Production issues acr_live_ keys, the rest acr_test_ keys
FrameworkReact, Angular, Node.js, Express, NestJS or Other. The overview uses it to pick a setup snippet
TypeFrontend, backend, full-stack, microservice, worker (mobile is listed as coming soon)
Description, version, tagsOptional. Tags are lowercase, up to 20

You become the owner and the app's billing owner: it follows your plan and counts toward your plan's app limit (20 on the default Free plan; archived apps count, deleted apps do not). When you reach it, creating an app shows the plan message with a View plan link.

Switch apps​

The app switcher lists every app you belong to, with a link to App settings, Members and Create app. The active app is part of the URL (/apps/<id>/…), not stored in your session, so you can have different apps open in different tabs. Opening / takes you to the app you used last.

The sidebar​

GroupPages
(top)Overview
MonitorAnalytics, Events, Errors, Logs, Performance
ControlControls, Flags
ConfigureAPI keys, Members, Settings

Every member can open every page. Pages explain when your role is read-only.

Overview​

The overview answers "is this app reporting to ACR?":

  • SDK connection – a status with icon and text (never colour alone):
StatusMeaning
Awaiting telemetry (pending)No SDK data received yet
ConnectedTelemetry is arriving
InactiveNothing received for INGEST_HEARTBEAT_TIMEOUT_SECONDS (5 minutes by default)
Ingestion errorThe API dropped a batch after retries. Check the API logs and database
  • Live visitors now and a seven-day visitors sparkline (browser SDK only).
  • SDK version, app version, last data received, last server heartbeat and the public app ID.
  • An SDK setup card with copy-ready code for React, Angular, plain browser, NestJS, Express and Node.js, using the right key prefix for the app's stage.

Settings​

Admins and owners can edit General (name, stage, description, framework, type, version, tags).

Changing the stage

A new stage only affects keys created afterwards. Existing keys keep working with their old prefix.

Danger zone​

ActionWhoEffect
Archive / RestoreAdmin, ownerArchived apps are read-only for developers and viewers; admins and owners keep access so they can restore or delete. SDK requests are rejected (ingestion and the control endpoint answer 403 APP_ARCHIVED), so an archived app stops collecting data
Transfer ownershipOwnerPick an existing member. They become owner and billing owner, and you become admin. Refused when the app does not fit in the new owner's plan
Delete appOwnerType the app name to confirm. The app is soft-deleted and all of its API keys are revoked immediately, so ingestion stops

You cannot transfer ownership to yourself, or to someone who is already an owner. An app can never be left without an owner.
