Observe everything

Analytics, events, errors, logs, performance, uptime and PM2 in one app-scoped view, so nothing lives in a separate tab.

Control anywhere

Feature flags, sample rate, log level, maintenance mode and announcements reach browsers and servers without a deploy.

Private by default

No stored visitor IPs. Query strings are stripped, sensitive values are redacted and Do Not Track is honoured.

import { ACRProvider } from '@lib-acr/react';

createRoot(document.getElementById('root')!).render(
  <ACRProvider
    config={{
      apiKey: import.meta.env.VITE_ACR_API_KEY,
      endpoint: import.meta.env.VITE_ACR_ENDPOINT,
      appVersion: '1.0.0',
    }}
  >
    <App />
  </ACRProvider>,
);
