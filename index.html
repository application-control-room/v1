Privacy and safety

Collect with restraint.

Privacy-minded defaults are built into the SDKs and the ingest path, not left to configuration.

No stored visitor IPs

An IP may be used in memory for a country lookup. It is never written to storage.

Sensitive values redacted

Query strings are stripped, emails are masked and sensitive values are redacted by default.

No inbound ports

SDKs send telemetry out and poll controls back. Nothing opens a port into your app.

Isolated per app

The credential decides which app receives data. A payload can never pick its own tenant.

Hashed server secrets

Server secrets are stored as a peppered HMAC and compared in constant time.

Good questions, straight answers.

What is ACR?

ACR is an Application Control Room. Its SDKs report visitors, events, errors, logs, performance and server heartbeats; its console turns that telemetry into useful views and delivers runtime controls back to your applications.

Which application frameworks are supported?

ACR has SDKs for browser JavaScript, React, Angular, Node.js, Express and NestJS. Services in any other language can send events over HTTP with the public events API.

Will telemetry slow down or break my application?

The SDKs are designed not to block or throw into your application. Calls write to bounded in-memory buffers, batches are sent in the background, and retries use backoff with jitter.

How quickly do remote controls apply?

SDKs normally poll the revisioned control snapshot about once a minute and refresh sooner when a browser tab becomes visible again or reconnects. Server polling can be configured, with a documented minimum interval.

Does ACR store visitor IP addresses?

No. An IP may be used in memory for country lookup, but it is not stored. Query strings are stripped, sensitive values are redacted, and browser collection honors Do Not Track by default.
