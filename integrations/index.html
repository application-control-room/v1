SDKs & integrations

Meet every application where it runs.

Use a framework binding when one exists, combine browser and server SDKs for full-stack visibility, or send events from any other language with the public events API.

See the setup stepsAsk about your stack
Setup

Connected in three steps.

The same copy-ready steps you get in the console, for every first-party SDK. Pick your runtime, install the package, add a key and start the app.

  • Browser SDKs use a publishable key that only works from the origins you allow.
  • Server SDKs use a key and secret that never leave your backend.
  • The first accepted event moves the app from awaiting telemetry to connected.
Create a free key
Connect your app

Install the SDK, add your key and start the app. Data appears in the console within a minute.

  1. 1

    Step 1: Install

    Browser SDK
    npm install @lib-acr/react
  2. 2

    Step 2: Add a publishable (client) key

    Create key
    VITE_ACR_API_KEY=acr_live_… # publishable (client) key
VITE_ACR_ENDPOINT=https://api.applicationcontrolroom.com/v1

    Client keys are safe in the browser and only work from the origins you allow.

  3. 3

    Step 3: Initialise

    import { ACRProvider } from '@lib-acr/react';

createRoot(document.getElementById('root')!).render(
  <ACRProvider
    config={{
      apiKey: import.meta.env.VITE_ACR_API_KEY,
      endpoint: import.meta.env.VITE_ACR_ENDPOINT,
      appVersion: '1.0.0',
    }}
  >
    <App />
  </ACRProvider>,
);

Choosing a package

Use the narrowest integration that matches your runtime.

Frontend application

Use React or Angular when those bindings match your framework; use the browser package for Vue, Svelte or plain JavaScript.

Backend application

Express combines the Node client with request middleware. NestJS provides the integrated module, interceptor, filters, logger and optional maintenance guard.

Full-stack application

Install a browser SDK and a server SDK with two credentials belonging to the same app—or use separate ACR apps when the deployment targets should be isolated.
